## At a glance

Code & Chill Lagos is a multi-page meetup site built with React, TypeScript, Vite, and Tailwind CSS. It follows the supplied starter brief: event information, a multi-session schedule, three speakers, an RSVP form, a footer, responsive behavior, and a theme toggle. Routes are `/`, `/day`, `/speakers`, and `/rsvp`.
